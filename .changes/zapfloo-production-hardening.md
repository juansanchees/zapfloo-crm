titulo: A instalação Zapfloo ganha uma página pública de exclusão de dados
---

O endereço público de exclusão de dados explica como uma pessoa pode solicitar a
remoção das informações da sua organização, requisito de preparação para a Meta.
Esta versão também corrige o envio pelo canal oficial quando as credenciais estão
salvas por organização e deixa os testes de instalação e atualização independentes
das credenciais Git existentes na máquina.
